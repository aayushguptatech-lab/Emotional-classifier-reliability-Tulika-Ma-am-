4. GENUINE DIALOGUE PATTERNS
----------------------------
Jaishankar Prasad's narrative style in Kankal uses several key dialogue structures:
  a) Explicit Attribution + Quoted Dialogue:
     Example: Kishori ne kaha, '...' / Niranjan ne puchha, '...' / Srichand ne kaha, '...'
     Prefix contains: Character Name + 'ने' + Attribution Verb ('कहा', 'पूछा', 'बोला', 'बोली', 'सुनाया', 'उत्तर दिया').
  b) Character Name + Dash + Quoted Speech:
     Example: Niranjan - '...' / Kishori - '...'
  c) Unattributed Continuation Dialogue (Quote Only):
     Sequential dialogue turns within high-tempo exchanges where Prasad omits explicit speaker attribution.
  d) Multi-Turn Paragraphs:
     Single prose paragraphs containing two or more character dialogue turns separated by narrative bridges or attributions.
  e) Direct Speech after Action / Modifier Phrases:
     Example: 'उत्तेजित किशोरी ने कहा,' / 'विरक्त होकर श्रीचन्द्र ने कहा,' / 'किशोरी ने हाथ जोड़कर कहा,'

5. FALSE-POSITIVE PATTERNS
--------------------------
Previous experimental extraction (51 turns) produced high contamination with invalid speaker tokens such as:
  'एक', 'वह', 'उस', 'सब', 'मैंने', 'फिर', 'डरते', 'भाव से'

Root Causes of Previous Errors:
  1. Naive Split on Hyphens / Dash: Generic dash splitting without verifying Devanagari Unicode name boundaries captured arbitrary words before dashes.
  2. Unrestricted Token Capture: Pronouns ('वह', 'उस', 'सब', 'मैंने'), numerals ('एक'), adverbs ('फिर'), and verb/action modifiers ('भाव से', 'डरते') were converted into speaker names.
  3. Lack of Validated Speaker Inventory: The previous builder had no character whitelist, permitting arbitrary string snippets as speakers.
  4. ASCII Word Boundary Bugs: Standard \b regex boundary fails on Hindi Devanagari text, causing name matching truncations.

7. EXTRACTION RISKS
-------------------
  1. Action Phrase Contamination: Prasad often prefixes speech with emotional state descriptions ('उत्तेजित किशोरी ने कहा', 'विरक्त होकर श्रीचन्द्र ने कहा'). Parser must isolate nominal subject ('किशोरी', 'श्रीचन्द्र').
  2. Pronoun & Generic Reference: Phrases like 'उसने कहा' or 'महात्मा ने कहा' must map to 'Unknown' rather than extracting 'उसने' or 'महात्मा'.
  3. Continuation Dialogue: 30-40% of dialogue turns lack inline character names. Explicit Unknown handling is required to avoid false attribution.
  4. Multi-Turn Paragraph Splitting: Paragraphs with multiple quote pairs must be split cleanly into individual rows.

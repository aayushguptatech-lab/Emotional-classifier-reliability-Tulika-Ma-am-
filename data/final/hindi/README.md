# Hindi outputs — provisional / experimental

Nothing in this directory is a validated final Hindi corpus.

Filenames containing `_final` record a pipeline snapshot. They do **not**
mean the extraction has passed the project's validation criteria.

## Gaban (प्रेमचंद) — PROVISIONAL

- Current snapshot: `gaban_dialogue_final.csv` (1010 turns)
- Review: `gaban_dialogue_review.csv`
- Validation note: `gaban_final_validation.txt`
- Status: source retrieval completed for 5 chapters. Narrative contamination
  remains. Not frozen.

Earlier snapshots (`gaban_dialogue_final_v8.csv`, `gaban_dialogue_final_v9.csv`,
segmented variants, and their validation files) are retained for audit.
